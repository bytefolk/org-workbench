① 连接线 = 汇报线

组织树从「缩进目录」升级为带 guide-rail 的连接图，选中岗位时祖先链路的连线点亮 lavender——「文件树即组织架构」第一次在视觉上成立。

② 岗位即端点

每个岗位带状态灯（在线/运行/离线）、微型预算条，hover 即出招聘与群聊入口。卡片是「设备档案」而非通用资料卡。

③ 回合即证据

对话面板保留 D3 的证据优先定位：状态行（engine · elapsed · tokens）、密封信封 digest、审批卡——以工程控制台语言呈现。

④ 预算即仪表

预算声明与消耗统一为双轨仪表：<80% 绿 / 80–100% 琥珀 / >100% 红，语义 token 全程贯通，暗色同步生效。
