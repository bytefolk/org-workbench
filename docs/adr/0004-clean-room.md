# ADR-0004: clean-room 纪律声明

状态：长期有效 ｜ 日期：2026-08-23

## 决策

org-workbench 全部代码为原创实现。竞品与参考项目（t3code、hermes-desktop、Hermes-Bot-Mode 等）只借鉴公开文档中可得的交互形态与进程形态思路，不复制、不改写、不翻译其任何源码；依赖面只引入 digital-employee 组织契约（钉版消费）与公开标准（Node.js 内建、Electron）。

## 执行要求

- PR 追溯表必须可回答"这段逻辑来自哪份自有文档/契约"；凡引用外部参考，注明"形态借鉴，代码原创"。
- 契约镜像（packages/shared）只对照 digital-employee 契约源，不参照任何第三方实现的字段。
- 评审时发现疑似移植代码，一律重写后合入。

## 理由

组织语义/预算治理/汇报链升级是我方原创产品定义；代码层面的清洁室是差异化叙事与法务安全的地基。
