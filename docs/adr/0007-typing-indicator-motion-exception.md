# ADR-0007: typing 指示动效例外登记（处方4）

状态：已决 ｜ 日期：2026-08-26 ｜ 依据：气泡聊天视觉规格 2026-08-26 §2②

## 决策

回合运行中的 typing 三圆点指示采用 1.05s ease-out 无限循环（6px 圆点、gap 4px、stagger 150ms）。此为 DS-31-001 处方4「动效禁 >300ms」的**登记例外**：

- typing 循环是聊天场景的标准进行中指示，与 AI thinking 指示同级，循环周期不适用单次动效上限；
- 仅此一例；其余动效仍守 120/150/200ms 三档 ease-out；
- prefers-reduced-motion 下循环动效归零（保留静态读屏文案）。

## 备选

antd Spin small（零例外）。默认三圆点，如需零例外可切换，接口不变。
